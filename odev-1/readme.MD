# Önemli Kısımlar

### 1. Kısım

Eğer kodu vscode terminalinden çalıştırıyorsanız Türkçe
karakterler gözükmeyecektir. Çünkü Türkçe değil, UTF-8 encoding
kullanıyoruz.

### 2. Kısım

Kodu çalıştırmadan önce

    pip install keyboard

komutunu terminale yazarak "keyboard" kütüphanesini,

    pip install logging

komutu ile ise "logging" kütüphanesini indirmelisiniz.
Aksi takdirde kod çalışmayacaktır.
